# aperas

A local-first knowledge graph, worked through a CLI and a small webapp — nodes and
the links between them are the source; any `.md` file you see is a projection, never
something to hand-edit.

## Install

```
npm install -g aperas
```

## Use it against an existing graph

```
cd path/to/your-graph
aperas serve
```

This starts (or reuses) the graph's service and prints a `http://127.0.0.1:<port>`
URL — open it in a browser to read and edit the graph.

A "graph" is a directory containing:

- `aperas.config.json` — `{ "name": "...", "graph": { "apeiron": "./Apeiron", "artifacts": "./artifacts" } }`
- `Apeiron/` — the graph's own on-disk store
- `artifacts/` — Markdown projections of the graph, regenerated by the tooling

## Commands

`aperas --help` lists every verb (`track`, `ingest`, `insert`, `update`, `remove`,
`tree`, `unfold`, `backlinks`, `serve`, `service`, ...); each has its own
`aperas <verb> --help`.
